# Callout conventions

Obsidian callouts are the cheapest way to mark **epistemic status**: which sentences are established,
which are guesses, and which are load-bearing. Both you and an agent reading the note later can then
tell the difference at a glance, which plain prose does not allow.

Use these five and no more.

> [!note] Note
> Context. True, uncontroversial, worth stating.

> [!hypothesis] Hypothesis
> Something you believe but have not shown. Say what would confirm or kill it.

> [!warning] Warning
> A trap, a confound, or a limit. The thing future-you will otherwise walk into.

> [!quote] Quote
> Someone else's words, with the source. Never paraphrase inside a quote callout.

> [!todo] Todo
> An action with an owner. If it has a date, put the date in it.

## The rule that matters

**A hypothesis must never be written as a note.** The whole point is that a reader can tell what is
established from what is hoped. Mislabel that once and the vault stops being trustworthy, which is
the only property it really has.
